# Security policy

Only `main` and the live app at [aetherion-kappa-two.vercel.app](https://aetherion-kappa-two.vercel.app) are supported.

Don't open a public issue. Report vulnerabilities privately via [GitHub security advisories](https://github.com/georgitinchev/aetherion/security/advisories/new). Expect a reply within 7 days.
